uno conserva su propia licencia; la licencia propietaria del proyecto no los
relicencia.

|---|---|---|
| [Python](https://www.python.org/) | Lenguaje y biblioteca estándar | PSF License |
| [NiceGUI](https://nicegui.io/) | Interfaz web y servidor local | MIT |
| [Quasar Framework](https://quasar.dev/) | Componentes de interfaz (vía NiceGUI) | MIT |
| [Apache ECharts](https://echarts.apache.org/) | Gráficos | Apache-2.0 |
| [SQLite](https://www.sqlite.org/) | Base de datos local | Public Domain |

| [ONNX Runtime](https://onnxruntime.ai/) | Motor de inferencia del OCR | MIT |

## Modelos de OCR

`rapidocr-onnxruntime` incluye modelos ONNX. Los modelos y sus pesos pueden
estar sujetos a las licencias de los proyectos que los originaron. Consulta la
documentación de RapidOCR antes de redistribuirlos.
